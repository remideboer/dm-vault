# XP-system  
[XP-calculator: donjon](https://donjon.bin.sh/d20/xp/)  
  

| uitdaging  | xp / pp            |
| ---------- | ------------------ |
| triviaal   | 10 * level * tier  |
| easy       | 25 * level * tier  |
| medium     | 100 * level * tier |
| hard       | 200 * level * tier |
| onmogelijk | 400 * level * tier |
  
De moeilijkheidsgraad wordt bepaald door de daadwerkelijke uirdaging (gevecht), zodat slecht of goed gooien, typische combo’s ook worden meegenomen in plaats van een statisch XP op basis CR.  
40 XP for a standard roleplaying encounter  
up to 60 for a more involved scene.  
  
Treasure collected  
1 gp = 1 XP, om te zetten bij een trainer
